# AI Image Classifier 🖼️🤖

A lightweight, web-based Artificial Intelligence image classification application built with Python and Streamlit. The app uses TensorFlow's pre-trained **MobileNetV2** model to instantly analyze and classify uploaded images.

### 🚀 [Try the Live App Here]([https://your-app-url.streamlit.app](https://manghiam-ai-image-classifier.streamlit.app/)

## 🛠️ Tech Stack
* **Frontend/UI:** [Streamlit](https://streamlit.io/)
* **Machine Learning:** [TensorFlow](https://www.tensorflow.org/) & Keras (MobileNetV2)
* **Image Processing:** OpenCV (opencv-python-headless)
* **Package Manager:** [uv](https://github.com/astral-sh/uv)

## ✨ Features
* **Real-time Classification:** Upload any image and get instant predictions.
* **Pre-trained Deep Learning:** Utilizes MobileNetV2 for high accuracy and fast inference without needing a local GPU.
* **Cloud Ready:** Configured for seamless deployment on Streamlit Community Cloud (headless environments).

## 💻 Local Setup & Installation

This project uses uv for lightning-fast dependency management. 

**1. Clone the repository:**
git clone https://github.com/GreenPlayerManghiam/ai-image-classifier.git
cd ai-image-classifier

**2. Run the application:**
Because uv handles virtual environments and dependencies automatically, you can just run the app directly:
uv run streamlit run main.py
